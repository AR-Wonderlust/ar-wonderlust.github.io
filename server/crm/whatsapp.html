Cuentas

Conectá una cuenta desde su teléfono. Solo se procesan mensajes nuevos de texto de los grupos que selecciones. No se importan chats privados, audios, fotos ni mensajes temporales.

En el teléfono: WhatsApp → Dispositivos vinculados → Vincular un dispositivo. El QR se actualiza mientras esta sección está abierta.

Grupos que querés monitorear

No selecciones el grupo interno como fuente. Cada grupo admite una sola cuenta recolectora. Al guardar autorizás avisos internos sobre las consultas detectadas.

Capturas y borradores

La extracción local propone datos para revisar. Abrí la ficha de cada consulta, completá lo que falta y guardá el borrador. El botón verde abre WhatsApp con el texto preparado; vos decidís cuándo enviarlo. Las consultas dudosas permanecen para revisión.

Se muestran las últimas 100 capturas. Estado «sent»: WhatsApp aceptó el aviso, no confirma lectura. Estado «unknown»: comprobar el grupo interno; no se reenvía automáticamente.
